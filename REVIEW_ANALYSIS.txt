# APP REVIEW & IMPROVEMENT ANALYSIS
# Hospital Intelligence Dashboard

## ISSUES FOUND:

### 1. CRITICAL ISSUES
- **TAB 5 Mislabeled**: "TAB 5 – REPORTS & EXPORT" comment exists but code missing
- **Payment Sources Tab Not in Sidebar**: Tab 8 (Payment Sources) exists but not in sidebar year filter selection
- **Duplicate Load Calls**: load_live_metrics() called 4+ times per page view (performance issue)
- **Missing Error Handling**: Payments CSV parsing could fail silently with skiprows=3

### 2. DATA QUALITY ISSUES
- **Inconsistent Column Naming**: 'Total_Paid' vs 'Total_Paid_To_Date' (aliases confusing)
- **Null Handling**: Missing Ward values fill with "Unknown Ward" but not consistent everywhere
- **Type Conversions**: Aging columns converted to numeric multiple times per tab view
- **Episode ID Consistency**: Converted to string in ingestion but numeric in reconciliation

### 3. PERFORMANCE ISSUES
- **No Dashboard Caching**: Full data reload on each filter interaction
- **Redundant Groupby Operations**: Ward analysis groups data then recalculates in display
- **CSV Encoding**: 4 encoding attempts per file read (utf-8, latin1, cp1252)
- **Memory Inefficiency**: Full dataframe loaded even when filtering by ward

### 4. UI/UX ISSUES
- **Inconsistent Metrics**: Some tabs show different collection calculation methods
- **Missing Ward Filter Integration**: Ward selector in sidebar but not applied to all tabs
- **No Data Refresh Indicator**: Users don't know when data was last updated
- **Truncated Tables**: Large result sets shown without pagination

### 5. CODE QUALITY ISSUES
- **Code Duplication**: Ward groupby logic repeated in multiple places
- **Magic Numbers**: skiprows=3 hardcoded for payment CSV
- **No Logging**: Errors only shown to UI, no backend logs
- **Long Functions**: load_live_metrics does 2 jobs (metrics + dataframe prep)

### 6. MISSING FEATURES
- **No Search/Filter**: Can't search by episode, hospital, or medical aid across tabs
- **No Data Export Per Tab**: Only full export available, no tab-specific exports
- **No Period Selector**: Hard-coded 2025 year, can't compare years
- **No Alerts**: No notification for poor collection rates or unusual patterns

### 7. LAYOUT ISSUES
- **Redundant Headers**: Each tab has identical subheader formatting
- **No Summary Cards**: Key metrics not accessible at top of page
- **Sidebar Clutter**: Only ward filter when could have date range, KPI type, etc.
- **Tab Overflow**: 8 tabs difficult to navigate without scrolling

### 8. DATA INTEGRITY
- **Silent Failures**: If CSV parsing fails, empty dataframe returned without warning
- **Aging Analysis**: Multiple columns could be null, calculations could be wrong
- **Episode Count**: Ward groupby().size() may not match actual episode count if data incomplete

## IMPROVEMENT OPPORTUNITIES:

1. ✅ Consolidate data loading to single cached call
2. ✅ Add comprehensive error logging and retry logic
3. ✅ Implement advanced filtering (episode, medical aid, date range)
4. ✅ Create reusable chart components to reduce duplication
5. ✅ Add data quality metrics dashboard
6. ✅ Implement period/year selector with year-over-year comparison
7. ✅ Add refresh timestamp and cache invalidation button
8. ✅ Optimize column selection to reduce memory footprint
9. ✅ Create helper functions for common metrics calculations
10. ✅ Add data export per tab with metadata
